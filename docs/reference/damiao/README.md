## 使用边界

该说明书描述的是达妙电机对外产品协议。重构时只借鉴以下原则：

1. 高频运行时控制与低频配置/诊断分离。
2. 固定、紧凑、可预测的控制帧。
3. 单一周期反馈帧携带关键状态和紧凑故障码。

不要直接复制其量程、控制模式、CAN ID 或故障定义；这些内容与本工程的硬件、
安全模型和校准流程不同。
